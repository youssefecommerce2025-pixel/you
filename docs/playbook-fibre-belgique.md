# Playbook — Générer des leads fibre Proximus depuis les réseaux sociaux (Belgique)

Guide stratégique et opérationnel pour un télévendeur freelance qui commercialise les offres
Proximus via une société belge agréée. Version web interactive : `/playbook.html`.

## 1. Contexte marché

- **Proximus** est le leader du haut débit fixe belge (~45 %, source BIPT/IBPT).
- Le déploiement **fibre (FTTH)** s'accélère : 2,4 M+ de foyers connectables ; objectifs 2028 de
  1,5 M en Flandre (Fiberklaar) et 600 k en Wallonie (Unifiber, désormais 100 % Proximus).
- Chaque mois, de **nouveaux foyers deviennent éligibles** → moment d'achat naturel (trigger).
- Concurrents : VOO/Orange (câble, Wallonie/Bruxelles), Telenet/BASE (national via wholesale).

## 2. Niche prioritaire

**Conversion fibre « trigger-based » en Wallonie + Bruxelles francophone** : adresses nouvellement
éligibles FTTH, encore chez VOO/Orange, Telenet/BASE ou sur DSL. Niche secondaire : **SOHO /
indépendants francophones** (panier plus élevé, moins saturé).

Éviter le cold-call résidentiel de masse « prix bas » (saturé, marge faible, plaintes DNCM).

## 3. Le canal : Meta Lead Ads + rappel < 15 min

- Le prospect **demande** un rappel (pas du cold call aveugle).
- CPL souvent **3–10 €** en Belgique si l'offre est bien ciblée.
- Le rappel ultra-rapide (**speed-to-lead**) est le vrai avantage : un lead non rappelé dans
  l'heure est quasiment mort.

## 4. Les 3 annonces (A/B/C)

Voir `/playbook.html` pour les textes complets prêts à copier :

- **A — Fibre / éligibilité** : « Fibre Proximus : vérifiez votre adresse ».
- **B — Débit qui chute le soir** : cible les insatisfaits VOO/Orange/Telenet.
- **C — Pack complet** : internet + TV + mobile, une seule facture.

Ciblage : Bruxelles + Wallonie, 25–55 ans, FR, intérêts internet/streaming/TV/gaming/télétravail.

## 5. Formulaire instantané

- Type **« Intention plus élevée »** (Higher intent).
- Champs : téléphone (obligatoire), code postal, opérateur actuel (QCM), objectif (QCM), consentement.
- Écran de remerciement avec bouton **« Appeler »** + promesse de rappel sous 15 min.
- Alternative : envoyer le trafic vers **ce site** (formulaire d'accueil) pour capturer la preuve
  de consentement et centraliser dans le CRM.

## 6. Script d'appel (résumé)

1. **Ouverture** : « Vous venez de demander une vérification fibre sur Facebook… »
2. **Éligibilité** : confirmer l'adresse, vérifier, annoncer le résultat (disponible / en cours / planifié).
3. **Qualification** : opérateur actuel, douleur (prix / débit / service), usage.
4. **Proposition & closing** : offre adaptée, bénéfice concret, réservation du raccordement.
5. **Objections** : « je réfléchis », « déjà chez X », « c'est cher », « pas le temps » → voir `/playbook.html`.

## 7. Setup Ads Manager

Objectif *Prospects* → *Formulaire instantané* · budget test 10–15 €/jour · Wallonie+Bruxelles ·
25–55 · FR · 3 annonces (A/B/C) · alerte instantanée des leads (Meta natif ou Zapier/Make).

## 8. KPI & routine

| Indicateur | Repère |
|---|---|
| Leads / jour (10–15 €/j) | ~2–6 |
| Coût par lead | ~3–10 € |
| Taux de joignables | 30–40 % |
| Closing (sur joignables) | 10–20 % |

Utiliser l'onglet **Analytics** du CRM (CPL par région) et le **simulateur de revenus**.

## 9. Conformité

- Licence **DNCM** (« Ne m'appelez plus ! ») obligatoire avant tout outbound.
- Consentement opt-in recueilli et **prouvé** (horodatage, IP, texte exact).
- Respect des horaires et de l'opt-out ; retrait du consentement facilité.
- Marques citées à titre informatif ; distribution via société agréée Proximus.
